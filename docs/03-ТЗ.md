# 03. Техническое задание (MVP)

## 1. Цель MVP

Проверить спрос: пользователь заполняет 5 параметров, получает осмысленный
маршрут по дням с партнёрскими ссылками. Замеряем конверсию и готовность
платить.

## 2. Сценарий пользователя

1. `/start` — приветствие, кнопка **«Спланировать поездку»**.
2. **Куда** — ввод стран/городов (можно несколько через запятую).
3. **Откуда** — город вылета.
4. **Даты** — ввод в формате `ДД.ММ.ГГГГ - ДД.ММ.ГГГГ` (или кнопки).
5. **Формат** — выбор кнопками: деловая / блогерство / отдых / культура /
   экстрим / своё.
6. **Бюджет** — число в рублях.
7. Отправка → шаг **оплата**:
   - «🆓 Бесплатный демо-план» — пример маршрута без затрат LLM;
   - «💳 Оплатить 690 ₽» — счёт в Telegram, полный маршрут выходит
     сразу после успешного платежа.
8. Результат:
   - краткое резюме;
   - маршрут по дням;
   - реальные цены на авиа (если доступны);
   - ссылки на билеты / отели / экскурсии;
   - чек-лист вещей.
9. Кнопки результата: **«Новый маршрут»**, **«Поделиться»**.

## 3. Функциональные требования

| ID | Требование | Приоритет |
|---|---|---|
| F1 | Сбор 5 параметров через FSM | Must |
| F2 | Валидация дат и бюджета | Must |
| F3 | Генерация маршрута через LLM (JSON) | Must |
| F4 | Партнёрские ссылки (авиа/отели/экскурсии) | Must |
| F5 | Рендер маршрута по дням | Must |
| F6 | «Новый маршрут» | Must |
| F7 | Сохранение маршрута | Should |
| F8 | Оплата разового полного маршрута (Telegram Payments) | Must (реализовано) |
| F9 | Реферальная ссылка | Could |
| F10 | Реальные цены авиа (Travelpayouts, fallback на monthly) | Must (реализовано) |

## 4. Нефункциональные требования

- Время ответа ≤ 30 сек.
- Устойчивость к ошибкам LLM (валидация JSON, retry, fallback-текст).
- Логирование запросов без персональных данных.
- Работа на VPS (Linux) и локально (Windows) без изменений кода.

## 5. Вне scope MVP

- Реальные цены в реальном времени (подключается в V1).
- Оплата и БД (V1).
- Мобильное приложение.
- Мультиязычность.

## 6. Критерии приёмки

- [ ] Бот запускается по инструкции из README без правок кода.
- [ ] Полный цикл «5 параметров → маршрут с ссылками» работает.
- [ ] При недоступном LLM бот не падает, а сообщает об ошибке.
- [ ] Все ссылки ведут на корректные партнёрские URL.

## 7. Переменные окружения

| Переменная | Назначение | Обяз. |
|---|---|---|
| `BOT_TOKEN` | токен Telegram-бота | да |
| `LLM_API_KEY` | ключ LLM | да |
| `LLM_BASE_URL` | базовый URL OpenAI-совместимого API | нет |
| `LLM_MODEL` | имя модели | нет |
| `AVIASALES_MARKER` | партнёрский маркер Aviasales | нет |
| `OSTROVOK_PARTNER_ID` | ID партнёра Ostrovok | нет |
| `TRAVELPAYOUTS_TOKEN` | токен для реальных цен | нет |
| `PAYMENTS_PROVIDER_TOKEN` | токен оплат (ЮKassa) | нет |
| `PRICE_PER_TRIP_RUB` | цена полного маршрута | нет |
| `CACHE_DIR` | папка кэша IATA | нет |
