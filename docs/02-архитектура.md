## 1. Общая схема

```
                   ┌──────────────────────────┐
   Telegram  ────► │  Бот (aiogram, Python)   │
   Сайт  ────────► │  FastAPI  API (опц.)     │
                   └────────────┬─────────────┘
                                │
                ┌───────────────┼────────────────┐
                ▼               ▼                ▼
        ┌────────────┐  ┌──────────────┐  ┌──────────────┐
        │ LLM-сервис │  │  Aggregator  │  │   Storage    │
        │ (GPT/…)    │  │  Clients     │  │ (SQLite→PG)  │
        └────────────┘  └──────┬───────┘  └──────────────┘
                               │
        ┌──────────┬───────────┼───────────┬──────────────┐
        ▼          ▼           ▼           ▼              ▼

   (авиа)        (отели)    (жд)        (экскурсии)  (2GIS/Ya)
```

## 2. Компоненты

### 2.1. Telegram-бот (MVP-ядро)

- Framework: **aiogram 3**.
- FSM-машина состояний для сбора 5 параметров.
- Кэш пользовательской сессии в FSM-storage (Memory → Redis в проде).

### 2.2. LLM-сервис

- Единый интерфейс к провайдеру (OpenAI-совместимый API).
- На вход — структурированный JSON с параметрами поездки.
- На выход — JSON-маршрут (см. схему ниже) + человекочитаемый текст.
- Модель обязана отвечать строго JSON (response_format / tool calling).

### 2.3. Aggregator-клиенты (V1)

| Направление | Источник | Тип доступа |
|---|---|---|
| Авиабилеты | Travelpayouts / Aviasales | официальный API |
| Отели | Ostrovok / Booking | affiliate API |
| ЖД | РЖД | парсинг/партнёр (нет публичного API) |
| Экскурсии | Tripster / Sputnik8 | affiliate-ссылки |
| Гео/логистика | 2GIS / Yandex Maps | API |

> В MVP aggregator-клиенты возвращают **шаблонные партнёрские ссылки**
> (см. `bot/app/services/affiliate.py`), поиск по API подключается в V1.

### 2.4. Хранилище (V1)

- MVP: без БД (или SQLite).
- Прод: PostgreSQL — пользователи, маршруты, заказы, события.

## 4. Поток запроса

```
Пользователь → /start
   → 5 вопросов (FSM)
   → PlannerService.build(params)
        → LLM.generate_itinerary(params)   # JSON
        → AffiliateService.links(params)    # партнёрские ссылки
   → рендер сообщения (по дням)
   → сохранение + re-engagement
```

## 5. Нефункциональные требования

- Ответ на запрос: **≤ 30 сек** (LLM + ссылки).
- Стоимость одного маршрута (LLM): **≤ 3-7 ₽** (короткий промпт, кэш).
- Хранение ПДн — по 152-ФЗ, минимизация, согласие при старте.
- Отказоустойчивость: fallback, если LLM/партнёрка недоступны.

## 6. Технологический стек

- **Bot:** Python 3.11, aiogram 3.
- **LLM:** любой OpenAI-совместимый провайдер.
- **HTTP:** httpx.
- **Конфиг:** pydantic-settings + `.env`.
- **Storage (V1):** PostgreSQL + SQLAlchemy.
- **Web (V2):** Next.js (SSR для SEO).
