# 01. Бизнес-план сервиса планирования путешествий

## 1. Суть продукта

Сервис, который превращает 5 входных параметров пользователя в **готовый
маршрут по дням** со ссылками на билеты, отели и экскурсии.

Входные параметры:

1. **Куда** — страна / город (можно несколько, галочками).
2. **Откуда** — город и аэропорт вылета/возврата.
3. **Даты** — период «с … по …».
4. **Формат** — деловая поездка, тревел-блогерство, отдых у моря,
   культура/экскурсии, экстрим и т.д.
5. **Бюджет**.

Выход:

- маршрут по дням и часам;
- партнёрские ссылки на авиа/жд билеты, отели, экскурсии;
- логистика (транспорт, рента авто, где ночевать);
- чек-лист вещей и сезонные советы.

---

## 2. Выбор платформы

| Платформа | Плюсы | Минусы | Роль |
|---|---|---|---|
| **Telegram-бот** | Запуск за недели, 0% комиссии стораджей, оплата в 2 клика (Stars / ЮKassa / СБП), встроенная вирусность | Ограниченный UI | **MVP, основной канал** |
| **Сайт** | SEO — бесплатный трафик, полный UI, гибкие лендинги | Дороже, дольше | **2-й этап, SEO-машина** |
| **Мобильное приложение** | Пуши, удержание | App Store/Google Play 15-30%, долго | **последним, если вообще** |

**Решение:** Telegram-бот → сайт → (опционально) приложение.

---

## 3. Монетизация

### 3.1. Основные источники

1. **Партнёрские программы (affiliate)** — базовый доход.
   - Авиабилеты: Aviasales через Travelpayouts — ~0.7-1.2% чека.
   - Отели: Ostrovok / Booking affiliate — 3-5% чека.
   - Экскурсии: Tripster / Sputnik8 / GetYourGuide.
2. **Разовая оплата за детальный маршрут** — 490-990 ₽.
3. **Премиум-доводка живым экспертом** — 2500-4000 ₽ (высокая маржа).
4. **Годовая подписка «Клуб путешественника»** — для частых поездок
   (бизнес, блогеры): безлимит маршрутов + приоритет поддержки.
5. **B2B** — корпоративные поездки, турагентства (позже).

### 3.2. Почему НЕ чистая подписка на старте

Путешествие — событие 1-2 раза в год. Месячный подписчик отвалится после
первой поездки. Поэтому смещаем ценность на **оплату за поездку**.

### 3.3. Рекомендуемая модель — Freemium + Up-sell

```
Бесплатно            →  краткий маршрут + affiliate-ссылки
Платно (разово)      →  полный маршрут по часам + чек-лист
Премиум              →  эксперт проверяет и бронирует
Клуб (год)           →  безлимит для частых путешественников
```

## 4. Экономика (упрощённо)

Допущения:

- Средний чек бронирования на пару: **180 000 ₽**.
- Доля тех, кто после маршрута бронирует через ссылки: **25%**.
- Средняя партнёрская ставка: **1.5%**.
- Доход с одной конвертированной пары: `180 000 × 1.5% ≈ 2700 ₽`.

Плюс прямые продажи маршрута (например 20% покупают за 690 ₽ = 138 ₽ на
пользователя). Плюс премиум ~3% × 3000 ₽ = 90 ₽.

**Вывод:** доход держится на **объёме трафика** и **конверсии в бронь**.
Ключевые метрики: CAC, конверсия маршрут→ссылка→бронь.

## 5. Каналы привлечения

1. **SEO** (сайт): статьи «что посмотреть в Кемере», «маршрут по Каппадокии».
2. **Telegram**: органические подборки, виральные маршруты, рефералки.
3. **Reels/Shorts/TikTok**: короткие «маршруты за 30 секунд».
4. **Партнёрство с тревел-блогерами**: маршрут как лид-магнит.
5. **Сарафанное радио** через реферальную программу внутри бота.

---

## 6. Риски и как гасим

| Риск | Митигация |
|---|---|
| Комиссии партнёрок низкие | Объём + допродажи (премиум, B2B) |
| Нет официальных API у части сервисов | Официальные affiliate API + парсинг там, где разрешено |
| Юридический статус турагента | Позиционирование «сервис планирования», бронь у партнёра |
| Иностранные сервисы недоступны из РФ | Приоритет российским партнёркам (Aviasales, Ostrovok, Tripster) |
| 152-ФЗ / GDPR | Явное согласие, минимизация данных, шифрование |
| ИИ выдаёт ошибочный маршрут | Дисклеймер + опция «проверить экспертом» |

---

## 7. Roadmap

- **MVP (0-1 мес):** Telegram-бот, 5 параметров → маршрут от LLM + affiliate-ссылки.
- **V1 (1-3 мес):** реальные API билетов/отелей, оплата, сохранение маршрутов.
- **V2 (3-6 мес):** SEO-сайт, премиум-доводка, реферальная программа.
- **V3 (6-12 мес):** B2B, мобильное приложение, интеграция туроператоров.
